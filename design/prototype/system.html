Drawlogic

System — the 12 components, in every state.

The screens show components assembled into one view at one moment. This page is the other axis: each component alone, in each state it can be in. Build the component once from here; the screens are then guaranteed to agree.

iRead first. Several states below never appear on a screen — a rule while it runs, a check on an unsigned rule, a flag after it is accepted. They are decided here so they are not improvised in code. Tokens are shared in styles.css; nothing on this page defines a colour, size or radius of its own.

01Button

Four variants, one shape. Pill radius from the export. Colour changes on hover; nothing moves or scales. A disabled button is always paired with the reason it is disabled.

  • Sentence case. No Title Case On Buttons. No exclamation marks.
  • Never scale, shrink or bounce on press. Colour change only.

  • Loading replaces the label with a linear sweep. It never spins. Reduced motion freezes it.
  • Amber is never a button. Blue is the only action colour.
